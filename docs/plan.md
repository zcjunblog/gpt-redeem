# 精简 PHP 兑换站 · 2026-10-22

用户已明确授权：将本地版本改为 PHP，按 aisub.online 样式实现，只接模拟接口，不接真实支付。

设计：参考当前 Chrome DevTools 捕获的 aisub 页面（浅灰、渐变标题、蓝色胶囊按钮、白色圆角单列卡片），三个标签：提交充值、进度查询、使用说明。流程：验证卡密 → 填虚构账号 → 确认并提交 → 等待结果。后台仅发码、卡密状态、订单查询/模拟异常处理，不做数据大屏。

技术：PHP 8.5.12 官方源码 SHA256 校验后在 .runtime 私有目录编译 CLI；PDO SQLite、session、filter、cURL、OpenSSL。无需 Composer、Node、Redis或常驻任务。公开目录 public/；配置和数据库在外面。

业务：卡密仅存哈希。事务抢卡并创建本站单；持久化模拟上游订单与幂等身份。提交直接调用 Mock；查单推进结果。成功须核对原单、账号、套餐，核销原子；超时查原单不重建。未知保持锁定；失败无自动放码。拒绝真实 Session/Token 和非虚构邮箱。

迁移：原 local-redeem/ 及数据库保留，PHP 用独立数据；先在3101验证，完成后停止已识别的旧服务，将PHP切到3100。回退时停止PHP、进入旧目录 npm start。没有真实业务数据迁移或删除。
